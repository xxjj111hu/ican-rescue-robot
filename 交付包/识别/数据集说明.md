# 数据集说明

## 1. 概述

- 训练用数据集：`交付包/识别/数据/`，共 **612 张 800×800 仿真抓帧**，全部人工标注
- 原始采集帧：2430 帧（自动采集，未全部标注）
- 类别：5 类地面贴图 —— 被困人员、救援营地、坍塌废墟、受损车辆、滑坡塌方
- 标注格式：YOLO 检测框（`class cx cy w h`，归一化到 0~1）

## 2. 目录结构

```
交付包/识别/数据/
  images/train/  images/val/     # 800x800 JPG
  labels/train/  labels/val/     # 同名 .txt，YOLO 格式

  README.md
```

## 5. 采集协议（可复现）

| 维度 | 取值 |
|---|---|
| 随机贴图分配 | 9 个 seed：[101, 102, 104, 105, 106, 107, 108, 109, 110] |
| 点位 | 0~4 号（五个地面贴图点全覆盖） |
| 相机到贴图距离 | 0.8 m、1.1 m、1.4 m |
| 车头偏角 | -20°、+0°、+20° |
| 采集方式 | `scripts/auto_collect.py` 自动换贴图 → 重启 Gazebo → 定点开车 → 抓帧 |
| 自动标签 | 类别来自 `shooting_texture_assignment.json`（每个点位当前是哪个类别） |

## 6. 覆盖性说明

- **点位覆盖**：0~4 号全部覆盖（0 号点不参与导航，但按验收要求采集）。
- **rotate 90**：所有地面贴图材质本身带 `rotate 90`，采集画面天然包含该旋转，无需额外处理。
- **随机性**：同一类别下有两张不同候选图片，通过 9 个 seed 让两张都在训练集中出现过。
- **标注**：全部为人工在 labelImg 中校正后的框，未使用伪标签。
