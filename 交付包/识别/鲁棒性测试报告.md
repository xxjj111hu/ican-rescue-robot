# 识别鲁棒性测试报告

## 1. 测试条件

| 项 | 值 |
|---|---|
| 模型 | ican_v9（YOLO11n，640 输入，mAP50 0.880） |
| 停车距离 | 相机到贴图 **0.8 m** |
| 点位 | 5 个（0~4 号），**随机贴图分配**，每个 seed 一套分配 |
| 判定方式 | 监听 `/referee/detections`，每点位连续采集 10 条话术 |
| 测试脚本 | `scripts/acceptance_run.py`（自动开车到停车位） |
| 节点判据 | 最近 7 帧投票 ≥4 票一致，且置信度 ≥0.45 才发话术 |

## 2. 结果：4 个随机贴图 seed，v9 对比 v6

| seed | v9 | v6 | v9 是否达标 |
|---|---|---|---|
| 201 | 80% | **94%** | ✗ |
| 202 | **96%** | 78% | ✓ |
| 203 | **92%** | 72% | ✓ |
| 204 | **96%** | 82% | ✓ |
| **均值** | **91.0%** | 81.5% | **3/4 达标** |

## 3. 逐点表现（v9）

| 点位类型 | 4 个 seed 的结果 | 稳定性 |
|---|---|---|
| 受损车辆 | 100 / 100 / 100 / 100% | 稳定 |
| 滑坡塌方 | 100 / 100 / 100 / 100% | 稳定 |
| 坍塌废墟 | 100 / 100 / 90 / 80% | 较稳 |
| 救援营地 | 100 / 80 / 70 / 100% | 波动 |
| 被困人员 | 0 / 100 / 100 / 100% | seed 201 全错 |

seed 201 的失败集中在 `trapped_people_02`（该变体补数据后仍只有 58 框，样本偏少）。

## 4. 与历史版本对比

| 版本 | 训练数据 | mAP50 | 多 seed 验收均值 |
|---|---|---|---|
| v6 | 612 张 | 0.739 | 81.5% |
| v7 | 612 张（同数据重训） | 0.672 | — |
| v8 | 760 张（+150 近距离） | 0.764 | 70.7% |
| **v9** | **912 张（+150 弱变体）** | **0.880** | **91.0%** |

关键经验：**按「贴图变体」补数据比按类别加数据有效**。v8 单纯加近距离数据反而退步；
v9 针对 4 个稀有变体各补 30 框，均值提升 10 个点。

## 5. 复现

```bash
bash scripts/eval_compare_seeds.sh      # 3 个 seed，v6/v9 各跑一遍
bash scripts/acceptance_run.py --dist 0.8 --per-point 10   # 单次
```
