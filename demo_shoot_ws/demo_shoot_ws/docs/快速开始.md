# 快速开始

## 1. 安装 ROS 2 Humble 和 Gazebo

本工作空间自带国内镜像安装脚本，适用于 Ubuntu 22.04 LTS：

```bash
cd ~/Ican_fly/demo_shoot_ws
bash scripts/00_install_ros2_gazebo.sh
```

如果系统已经安装好 ROS 2 Humble 和 Gazebo Classic，可以跳过这一步。

## 2. 安装仿真环境

```bash
bash scripts/01_install_sim_deb.sh
```

Demo 中的 deb 只安装最简运行所需的 `ican_land_control`、`ican_land_sim` 和 `ican_shoot_sim`，不会安装完整工作空间中的其他功能包。

仿真环境会安装到：

```text
/opt/ican_shoot_sim
```

## 3. 加载环境

```bash
source scripts/setup_env.sh
```

环境脚本会自动加载 Gazebo Classic 的系统资源路径，不需要手动设置 `GAZEBO_RESOURCE_PATH` 或 `GAZEBO_MODEL_PATH`。

也可以手动执行：

```bash
source /opt/ros/humble/setup.bash
source /opt/ican_shoot_sim/setup.bash
```

## 4. 启动仿真

带 Gazebo 界面启动：

```bash
bash scripts/run_sim.sh
```

无界面启动：

```bash
bash scripts/run_sim.sh gui:=false
```

底层等价命令：

```bash
ros2 launch ican_shoot_sim sim.launch.py
```

## 5. 检查环境

如需确认环境是否安装正确：

```bash
bash scripts/check_sim_env.sh
```

## 6. 运行示例代码

```bash
colcon build --symlink-install
source install/setup.bash
bash scripts/run_example_mission.sh
```

脚本会打开三个终端标签，分别启动仿真、导航和示例程序。示例使用预设的 2/3/4 号靶配置（ID 分别为 1、6、8），不需要手动输入；当前示例会启动环形靶瞄准，让小车到达 1 号任务点后发布 `shoot_1` 点位消息并射击。

## 7. 更换地面贴图和配置权限

本工作空间包含 0～4 号地面点的 10 张候选贴图。首次使用或需要给其他用户开放贴图替换权限时执行：

```bash
source scripts/setup_env.sh
./scripts/randomize_ground_textures.sh --setup-permissions --add-user "$USER"
```

其他用户可追加多个 `--add-user`：

```bash
./scripts/randomize_ground_textures.sh --setup-permissions \
  --add-user 用户1 --add-user 用户2
```

权限配置完成后，当前用户需要刷新一次用户组会话。可以退出系统后重新登录，或者在当前终端执行：

```bash
newgrp ican_shoot_sim
```

其他用户也需要各自重新登录，或在自己的终端执行 `newgrp ican_shoot_sim`。执行 `newgrp` 后会进入一个新的 shell 子会话，后续命令在这个子会话中运行；完成后输入 `exit` 可返回原 shell。

组权限已经生效后，直接运行：

```bash
./scripts/randomize_ground_textures.sh
```

说明：`--setup-permissions` 只需配置一次。以后只是随机更换贴图，不需要再次输入密码，也不需要重复执行 `newgrp`，除非用户组或权限被重新修改。

脚本每次从五个类别中各选择一张图片，随机分配到 0～4 号地面点，并保持识别任务的 `rotate 90` 规则。`--seed 数字` 可复现结果，`--dry-run` 只查看映射。日志位于 `logs/randomize_ground_textures.log`；贴图替换失败、权限不足或文件异常都会记录。替换后需要重启 Gazebo。

示例源码在 `src/` 目录下，构建产物会生成在当前工作空间的 `build/`、`install/` 和 `log/` 目录中。

示例默认使用调优后的 Nav2 参数和简洁 RViz 配置。RViz 中如果看到大量绿色小箭头，那通常是 AMCL 粒子云显示，不是导航目标。
